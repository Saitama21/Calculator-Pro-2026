# Calculator Pro 2026
Responsive Russian-language offline PWA with photorealistic WebP machining cards, light/dark themes, four interactive speed/feed calculators, local history and clipboard export.

GitHub Pages: Settings → Pages → Source: GitHub Actions. The supplied workflow deploys main.

Input cutting speed and feed yourself; material selection does not prescribe manufacturer cutting data. Power, forces and machining time are outside v0.1 scope.

Run locally: python3 -m http.server 8080
